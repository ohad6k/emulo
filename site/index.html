Questions.

How do I make my AI agent write code the way I do?

Start with what it keeps missing. The free report shows where you repeat yourself to the agent. Mining goes further: it turns the rules that recur across your sessions into a you.md your agent loads before a task, with dated quotes behind every rule. Whether that changes how the agent works for you is worth testing on your own work. Our own 60 run test is public, including the part that did not go our way.

How is this different from agent memory?

Memory stores what you told the model. Emulo reads the messages you actually typed across many sessions and pulls out what keeps recurring, with the dates it came from. The rules you remembered to write down on a good day are usually a smaller set than that.

Is this just a CLAUDE.md or a rules file?

The output is a file like that, and you can edit it like one. The difference is where it comes from. Every rule is derived from real sessions and carries dated quotes, and emulo verify checks that each quote actually exists in your logs.

Do my session logs leave my machine?

The coach report makes no model call and runs entirely on your machine. For a profile, extraction, redaction, caching and the profile itself stay local, and secrets are redacted before anything is written. The one exception is the mining pass: if your agent uses a hosted model, the selected evidence goes to that provider. A local model keeps the whole run on your machine.

Which coding agents does it work with?

It reads Claude Code, Codex, Copilot CLI, OpenCode, and Google Antigravity logs out of the box. It does not read Cursor sessions, but it installs profiles for Cursor and Gemini through explicit adapters. It also ships an MCP server, so any MCP client can load a profile mined through the agent flow before a task.

What does it cost to run?

The tool is MIT licensed and free. The coach report makes no model call, so running it costs nothing. Mining spends model calls to read your history. When an agent mines for you through run emulo, it shows a read-only plan with the cost first and waits for your approval before any model work starts. The plain emulo command makes no model calls: it writes chunks and a RUN_ME.md, and the model work happens when you hand that file to your agent.

How much history do I need?

Any. The report counts whatever you have. For a profile, more sessions help, since a rule only earns a place when separate sessions keep supporting it. The example profile on this page came from 1,656 sessions over nine months.
