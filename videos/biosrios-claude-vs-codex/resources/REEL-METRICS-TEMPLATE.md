Platform-reported fields are views, holds, watch time, completion, replays,
saves, shares, total comments, profile visits, and follows/subscribers. Never
estimate a platform value; label unavailable values N/A.

Keyword comments are manually counted. Keyword comments per 1,000 views are
calculated separately at 24 hours and 7 days as `(keyword comments in the
window / views in the same window) x 1,000`. Record manual and calculated
values only from the captured window.
